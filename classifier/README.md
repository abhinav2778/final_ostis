# Module 3 — Classification

Two-stage classification: binary threat detection, then 7-class industry
tagging. Both use fine-tuned `markusbayer/CySecBERT`.

## Pipeline order (important — has a bootstrap dependency)

1. `finetune_binary.py` — fine-tunes CySecBERT on threat vs. AG News
   (non-threat). No label file needed; positive class comes directly from
   `storage/processed_articles.csv`.
2. `classify_bootstrap.py` — runs `facebook/bart-large-mnli` zero-shot
   classification to produce **initial industry pseudo-labels**
   (`classifier/tagged_articles.csv`). This only needs to run once — it
   exists purely to bootstrap training data for step 3, since we don't
   have hand-labeled industry data.
3. `finetune_industry.py` — fine-tunes CySecBERT on the bootstrap labels,
   with **class-weighted loss** (`compute_class_weight("balanced")`).
   This is not optional — Finance/Healthcare/Education are minority
   classes in practice (10-20x fewer samples than ICS), and without
   weighting the model learns to ignore them entirely.
4. `classify_finetuned.py` — production inference using both fine-tuned
   models. This is what the incremental pipeline (Module 7) actually
   calls. No BART/zero-shot dependency — single forward pass per stage.

## Run

```bash
python classifier/finetune_binary.py
python classifier/classify_bootstrap.py     # one-time bootstrap
python classifier/finetune_industry.py
python classifier/classify_finetuned.py     # production classification
```

## Notes

- Device auto-selects MPS (Apple Silicon) → CUDA → CPU.
- Model artifacts are saved to `classifier/finetuned/{binary,industry}/`
  and are gitignored (large binary files, regenerated by training).
- `label_map.json` inside `finetuned/industry/` maps integer class IDs
  back to industry names — required by `classify_finetuned.py`.
